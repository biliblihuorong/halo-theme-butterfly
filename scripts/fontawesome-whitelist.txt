# Font Awesome 图标白名单(一行一个,支持 # 注释)
#
# 子集化脚本(scripts/subset-fontawesome.mjs)最终生效的图标 =
#   自动扫描 src/html、src/js、settings.yaml 中用到的图标 + 本白名单。
#
# 写法:
#   fa-brands fa-telegram   # 指定字体族
#   fa-qq                   # 不指定族 = 加入所有包含该图标的字体族(字节数差异可忽略)
#
# 场景:在后台"主题设置"里新增了社交图标、或改了可配置的图标项之后,
#       把新图标名加进来,然后运行 pnpm subset:fa 重新生成,再重新构建主题。
#
# 注意:本主题内置 Font Awesome Pro 6.1.0。fa-x-twitter(6.4+)与
#       fa-netease-cloud-music(不在 FA 图标集内)在该版本中不存在,勿添加。
