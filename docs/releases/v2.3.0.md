# Butterfly v2.3.0

本版本聚焦访客体验和加载性能：图片加载更稳更快、代码高亮按需加载、评论区延后加载，并新增可选的图床预览图。所有新功能均有设置开关，已保存的站点配置不会被改变。

## 新功能

### 图片预览图（可选，默认关闭）

图床能按规则生成缩略图时，在 **主题设置 → 性能优化 → 图片预览图** 中开启，三种地址规则任选其一：

| 规则 | 示例 |
| --- | --- |
| 追加查询参数 | `a.webp` → `a.webp?w=400` |
| 替换路径前缀 | `/i/a.webp` → `/thumbnails/a.webp` |
| 文件名后缀 | `a.webp` → `a_thumb.webp` |

- 文章列表与归档封面只加载预览图，失败时回退原图。
- 首屏背景和正文图片先显示预览图，原图加载完成后替换；预览图失败时直接加载原图。
- 点击放大始终打开原图。
- 只处理“应用预览图的图床域名”中列出的域名；留空时只处理本站图片。Halo 附件库的本地图片已自带 `srcset` 缩略图，主题不会改写。

### 尊重“减少动态效果”

访客在系统中开启“减少动态效果”时，主题关闭过渡、动画、平滑滚动和打字机效果。

## 改进与修复

| 项目 | 变化 |
| --- | --- |
| 图片来回滚动重复加载 | 改用浏览器原生懒加载。此前图片未加载完就滚出视口会被取消，滚回来重新下载；且图片到眼前 300px 才开始加载 |
| 首屏背景图 | 在 `<head>` 中高优先级预加载，不再等待主题脚本执行（随机图 API 除外） |
| 代码高亮 | Prism 升级到 1.30.0（修复 CVE-2024-53382）。主文件由 586KB 降到 53KB（gzip 约 18KB），文章用到的语言才加载；不支持的语言按纯文本显示，不发请求 |
| Shiki 等高亮插件共存 | Prism 改为手动模式，不再自动扫描整页触及插件接管的代码块 |
| Artalk 评论 | 评论区接近视口或通过评论锚点进入页面时才加载资源 |
| 页面 Loading | 新安装默认关闭；开启时 300ms 内就绪不显示，只在遮罩可见时锁定滚动（此前加载期间无法滚动页面） |
| Cloudflare Rocket Loader | 首屏配置脚本不再被推迟执行，避免配色闪烁和预加载失效 |

## 升级

1. 从 Release 下载 **theme-butterfly-dist.zip**（可用 `.sha256` 与 `.manifest.json` 核对），在后台上传覆盖安装，然后执行“重载主题配置”，让新设置项出现在表单中。
2. 需要预览图时，在“性能优化”中开启并填写规则和图床域名。
3. 清理 CDN 中缓存的 HTML 和主题静态资源，确认页面请求包含 `v=2.3.0`。使用自定义或 npm CDN 加载静态资源时，需同步完整的新资源，其中包括新增的 `plugins/prism/components-1.30.0/` 语言目录。

已保存配置中的 Loading 类型保持不变；如希望使用新的默认行为，可在“加载与资源”中手动关闭页面 Loading。

## 验证

- 56 项回归测试通过，新增预览图三种规则与域名过滤、加载失败回退链、占位图事件竞态、渐进替换、Prism 打包与未知语言、评论懒加载等用例。
- 在 Halo 2.24.2 上安装构建产物，用无头浏览器实测：首屏预加载预览图并替换原图、封面来回滚动只请求一次、正文远处图片滚动到附近才加载、Prism 只加载用到的语言、启用 Shiki 时不加载 Prism，首页、归档、分类、标签、分页、404 和文章页均无脚本错误。
