# Butterfly v2.3.2

本次更新在右下角浮动工具栏加入简繁切换、宽屏阅读和评论快捷入口，访客无需修改后台配置即可使用。

## 新增与改进

- **简繁切换**：点击“繁”将页面文字转换为台湾正体，再次点击恢复原文；偏好保存在访客浏览器。OpenCC 词库从主题本地按需加载，跳过代码、输入框、第三方评论和不需要转换的内容。动态文字与文章目录同步转换，切回时保留原文及空白。
- **宽屏阅读**：桌面文章页和普通独立页面可隐藏侧栏，让正文占满原有主容器，并记住选择。按钮仅在页面有侧栏且宽度大于 1100px 时显示；手机保持原有布局与目录行为。
- **评论快捷入口**：页面有可用评论区时显示。点击后跳到评论区并立即启动 Artalk 加载，保留滚动到附近自动加载；两种入口共用初始化流程，重复点击不会重复加载。也支持定位 Halo 评论组件。
- **工具栏与目录**：键盘聚焦时显示工具栏；限制短屏下的工具栏和手机目录弹层高度，内容过长时可滚动。
- **文档与资源**：更新[配置说明](https://github.com/biliblihuorong/halo-theme-butterfly/blob/v2.3.2/docs/configuration.md#访客阅读工具)与[开发文档](https://github.com/biliblihuorong/halo-theme-butterfly/blob/v2.3.2/docs/development.md#简繁转换资源)，安装包包含 OpenCC 许可声明和新增按钮所需的图标子集。

本次没有新增后台配置字段，现有配置无需迁移。普通独立页面仍不新增目录，瞬间与图库保持现状。

## 升级

1. 下载 `theme-butterfly-dist.zip`，在 Halo 后台上传覆盖安装。
2. 清理浏览器或 CDN 缓存，确认主题 CSS/JS 请求中的版本参数为 `v=2.3.2`。
3. 使用自定义 CDN 时，同步本版本完整的 `templates/assets/`，包括带内容哈希的简繁异步词库，避免混用旧资源。

发行包附带 `.sha256` 与 `.manifest.json` 校验文件。
