# Butterfly v2.2.10

本版本修复对线上站点（2.2.9）抓取和浏览器检查中发现的问题，重点是 Steam / 追番页脚本崩溃。

## 修复清单

| 编号 | 修复 | 新行为 |
| --- | --- | --- |
| 1 | Steam、追番页脚本加载即报错 `ES Modules may not assign module.exports`，页面模块全部未初始化 | 局部导航模块改为 ESM 导出，两页的筛选和分页局部刷新恢复正常；新增测试禁止浏览器源码使用 CommonJS 导出 |
| 2 | 启用 Shiki 等代码高亮插件时，主题仍加载 Prism 并处理插件已接管的代码块 | 跳过 `<shiki-code>` 内的代码块；正文全部由插件渲染时不再加载 Prism 脚本和样式 |
| 3 | 深色模式行内代码对比度仅 1.92:1，难以辨认 | 深色约 7:1、浅色约 5:1，满足 WCAG AA |
| 4 | 首屏内联脚本只读取本地存储，忽略“主题模式”设置，auto / 固定模式下可能先按旧偏好绘制再切换 | 首屏按与主题脚本相同的规则（auto / light / dark / user）确定配色 |
| 5 | 只识别 `html.dark` 的插件组件（如 Steam 卡片）在深色模式下仍为浅色 | `<html>` 同时同步 `dark` / `light` class，符合 Halo 插件配色约定 |
| 6 | 分页页面标题与第一页相同；分类、标签详情页标题是固定文字 | 首页、分类、标签、归档、朋友圈从第 2 页起追加“第 N 页”；分类、标签页使用其名称 |
| 7 | 访问超出总页数的分页时只显示“暂无数据”，无法返回 | 仍渲染分页，可直接跳回有效页 |

## 升级

1. 从 Release 下载 **theme-butterfly-dist.zip**（同时可下载 `.sha256` 与 `.manifest.json` 核对），在后台上传覆盖安装。本版本没有配置项变更，无需迁移。
2. 清理 CDN 中缓存的 HTML 与主题静态资源，确认页面请求包含 `v=2.2.10`。
3. 检查 Steam、追番页的控制台无报错，以及文章页代码块在明暗模式下的显示。

主题自带的 Prism 已覆盖代码高亮、明暗主题、行号、复制、折叠与标题。如不需要 Shiki 的 `[!code ...]` 行标记或瞬间页代码高亮，可以停用 Shiki 插件，由主题统一处理。

## 验证

- 38 项回归测试全部通过，新增局部导航导出、Shiki 共存、越界分页和 `dark` class 同步用例。
- 对比执行构建产物：2.2.9 的 `steam.min.js` 复现上述报错；新构建的 Steam、追番脚本均正常注册局部导航模块。
- 分页标题的 Thymeleaf 表达式未在 Halo 实例上渲染验证，升级后请留意分页页的 `<title>`。
