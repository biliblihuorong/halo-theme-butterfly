# Butterfly-shell v2.3.6

本版调整列表与侧栏的布局细节，拆分公共样式以消除非首页的样式闪动，缩小图表脚本体积，并修复鼠标指针图标 404。v2.3.5 没有单独打标签发布，它的封面修复与社区身份材料一并包含在本版中。

Butterfly-shell 是由 shell 维护的社区派生版本，不代表 Halo 官方、上游 Halo 移植版维护者或 Hexo Butterfly 原作者。来源、差异和上游贡献的实际状态见[派生与应用市场说明](https://github.com/biliblihuorong/halo-theme-butterfly/blob/v2.3.6/docs/marketplace.md)。

## 布局与阅读

- **浮动按钮不再压住侧栏**：屏幕宽度在 1101–1340px 之间时，右侧空白放不下回到顶部等浮动按钮，按钮会压在侧栏卡片上（1280px 宽时重叠 18px）。现在主容器右侧会让出按钮的位置，按钮与侧栏之间保留约 16px 间隙；空白足够时布局不变。触屏设备上，按钮从 35px 放大到 44px，更容易点中。（[#9](https://github.com/biliblihuorong/halo-theme-butterfly/pull/9)）
- **隐藏为 0 的计数**：文章卡片上的「评论」「点赞」「预览」，数值为 0 的那项不再显示；三项都为 0 时整行不显示。（[#9](https://github.com/biliblihuorong/halo-theme-butterfly/pull/9)）
- **分类页、标签页不再重复显示**：`/categories` 页面的正文已经列出全部分类，侧栏就不再显示「分类」小部件；`/tags` 页面同理，侧栏不再显示「标签」小部件。其他页面的侧栏不受影响。（[#9](https://github.com/biliblihuorong/halo-theme-butterfly/pull/9)）

## 性能

- **公共样式单独加载**：所有页面共用的样式输出为 `css/common.min.css`，各页面的 CSS 只保留本页差异部分，两者都在 `<head>` 中同步加载。之前的做法是：非首页先加载完整的 `index.min.css`，页面自己的 CSS 再异步挂上，所以会先按首页样式绘制一次，然后切换。现在首屏会直接按当前页面的样式绘制。首屏 CSS 体积：文章页从 73.7 KB 降到 39.5 KB，分类页从 65.7 KB 降到 31.3 KB，首页保持 34.4 KB。（[#10](https://github.com/biliblihuorong/halo-theme-butterfly/pull/10)）
- **图表脚本缩小**：归档、分类、标签页的 ECharts 异步包从 1.01 MiB 降到 593 KiB，gzip 后从 336 KiB 降到 196 KiB。做法是列出实际用到的图表和组件，没用到的不再打包。图表仍然要等滚动到附近时才加载。（[#10](https://github.com/biliblihuorong/halo-theme-butterfly/pull/10)）

以上是构建产物的体积，不能直接代表线上加载时间。

## 修复

- **鼠标指针 404**：启用自定义指针后，悬停在链接和按钮上时，浏览器会去请求 `css/simple/pointer.cur`，结果 404，指针退回系统默认样式。现在改为用完整地址加载指针文件。（[#10](https://github.com/biliblihuorong/halo-theme-butterfly/pull/10)）
- **主题资源根路径**：本站资源地址改为由 Halo 的 `#theme.assets()` 生成，不再手动拼接 `/themes/{name}/assets/`。默认部署下生成的地址不变。（[#10](https://github.com/biliblihuorong/halo-theme-butterfly/pull/10)）

## 包含的 v2.3.5 改动

- **响应式封面**：预览图模式下，如果 `src` 暂时是占位图、真实地址在 `data-lazy-src` 里，而插件用 `data-responsive-src` 标明了这些候选属于同一张真实图片，就保留它的 `srcset`，交给浏览器自己选图。没有匹配标记的占位图候选仍会被移除。真实候选加载失败时，先撤下 `srcset` 重试原图，再失败才显示错误占位图。（[`7f15c5a`](https://github.com/biliblihuorong/halo-theme-butterfly/commit/7f15c5a)）
- **项目图标与身份**：主题元信息改用本项目的蝴蝶图标，简介和文档写明这是社区派生版本。补充了派生来源、安装、配置迁移和回退的说明。

本版继续使用 `theme-butterfly-shell`、`theme-butterfly-shell-setting` 和 `theme-butterfly-shell-configmap`，没有新增或改名的主题配置字段。

## 安装与升级

1. 先备份 Halo 数据和当前的主题设置，并留好当前版本的 ZIP。然后下载本版的 `theme-butterfly-dist.zip`，可以用一起提供的 `.sha256` 和 `.manifest.json` 核对版本和完整性。
2. **全新安装**：在 **主题管理 → 安装主题** 上传 ZIP，预览后启用 **Butterfly-shell**。
3. **从 v2.3.4 升级**：在 `theme-butterfly-shell` 的详情页选择 **··· → 升级**，上传本版即可，不需要转换配置。
4. **从 v2.3.3 及以前的 `theme-butterfly` 迁移**：必须用“安装主题”安装新主题，并保留旧主题，不能在旧主题的“升级”入口上传本版。具体步骤见[从旧主题标识迁移](https://github.com/biliblihuorong/halo-theme-butterfly/blob/v2.3.6/docs/configuration.md#从旧主题标识迁移到-v234)。
5. 如果用的是自定义 CDN，请同步本版的完整资源，其中包括新增的 `css/common.min.css` 和新的 echarts 异步包。之后清理页面缓存和浏览器缓存，确认资源的版本参数是 `v=2.3.6`。
6. 升级后检查首页、文章页、分类页、标签页、归档页的样式和图表，以及评论和已安装插件的页面。

## 回退

在同一个主题标识内回退时（例如从 v2.3.6 回到 v2.3.4）：先启用另一个已验证可用的备用主题；然后对 `theme-butterfly-shell` 选择普通的“卸载”，保留配置；再安装原来版本的 ZIP；最后通过 `json-config` 接口恢复升级前的配置备份，回读确认后重新启用。不要选择“重置”或“卸载并删除配置”。如果用了自定义 CDN，也要把 CDN 上的资源恢复到原版本。完整说明见[回退步骤](https://github.com/biliblihuorong/halo-theme-butterfly/blob/v2.3.6/docs/configuration.md#回退到升级或迁移前的版本)。

## 验证

- `pnpm test` 的 123 项回归测试全部通过，新增的用例覆盖：页面样式不再重复打包公共样式、页面同步加载样式、指针使用完整地址。`pnpm build-zip` 和 `verify-release` 也都通过。
- 在隔离的 Halo 2.24.2 实例上安装本版构建的主题，再用 Playwright 在 1280×800 和 375×812 两种尺寸下逐页检查。检查的页面有首页、文章、分类、分类详情、标签、标签详情、归档、独立页面和 404 页，结果如下：
  - 状态码都符合预期，没有 JS 报错。
  - 拆分样式前后的整页截图除动态数据外完全一致。
  - 三种图表都能正常绘制。
  - 浮动按钮不再压住侧栏。
  - 页面上不再有 404 请求。

**维护者的人工验收还没有完成**，自动化测试和浏览器自动化的结果不能当作人工验收已通过。待办清单见[重新提交前的验收记录](https://github.com/biliblihuorong/halo-theme-butterfly/blob/v2.3.6/docs/marketplace.md#重新提交前的验收记录)。
