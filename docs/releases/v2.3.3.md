# Butterfly v2.3.3

本次更新优化图片加载与公共脚本体积，将页脚主题署名改为项目名称和仓库链接，并补充友链标题及主题更新方式的说明。

## 改进与修复

- **页脚署名**：显示 `halo-theme-butterfly v2.3.3`，点击前往本主题仓库；版本号随实际安装版本变化。链接直接使用仓库地址，兼容未向模板公开 `theme.spec.website` 的 Halo 版本。
- **原生响应式封面**：关闭图床预览时，列表与归档封面输出真实图片地址，让 Halo 2.22+ 为支持缩略图的附件自动添加 `srcset`；主题按列表、网格、侧栏和屏幕尺寸提供 `sizes`。候选加载失败时撤下 `srcset`，先重试原图，再显示错误占位图；调整窗口后切换候选的失败也会回退。
- **预览图兼容**：清除属于占位图的响应式候选，避免干扰真实图片；正文已有的 `srcset` 保留，不会因预览规则而额外下载原图。
- **按需图片灯箱**：页面主内容区存在图片时才加载 Fancybox 及其样式，保留原图放大和工具栏。公共脚本从约 248 KB 降至 82 KB，gzip 估算从约 73 KB 降至 25 KB；这些是构建产物大小，不能直接代表线上加载时间。
- **查询复用**：桌面与移动侧栏共享菜单及标签总数，减少重复 Finder 调用。
- **ImgNest 单档预设**：已有图片预览规则新增可选的 `imgnest` 模式，将配置域名内的图片映射到同目录 `_thumbs.webp`，缺失时回退原图。保留目录与编码路径，跳过已有缩略图、未知扩展名和查询参数链接；预览功能仍默认关闭。
- **文档**：说明友链标题由链接管理插件的“页面标题”控制，并补充 Halo 响应式图片适用范围、ImgNest 配置、性能约定和应用市场更新提示的接入条件。

本版仅支持 ImgNest 现有单档缩略图，不请求多尺寸接口；多尺寸能力完成后另行接入。没有新增独立页面目录，也不包含瞬间和图库的页面功能改造。

## 升级

1. 下载 `theme-butterfly-dist.zip`，在主题详情页右上角 **··· → 升级** 上传安装。
2. 执行“重载主题配置”，以显示新增的 ImgNest 预览规则选项；已有设置无需迁移，预览功能不会自动开启。
3. 确认资源版本参数为 `v=2.3.3`。使用自定义 CDN 时同步本版完整资源，包括带内容哈希的 Fancybox 异步包。
4. 需要将友链页标题改为“友情链接”时，在 **插件 → 链接管理 → 基本设置 → 页面标题** 修改并保存；升级主题不会覆盖插件标题。

发行包附带 `.sha256` 与 `.manifest.json` 校验文件。当前仍通过 GitHub Releases 分发，Halo 原生更新提示需后续上架应用市场并绑定本 fork 的应用 ID。
