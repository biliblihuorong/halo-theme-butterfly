# Butterfly v2.3.1

本次小补丁修复 Umami 统计显示与侧栏自定义路由，并重新整理项目介绍和使用文档。

## 修复与改进

- **Umami 统计**：浏览器拒绝写入本地缓存时，成功取得的访问量仍会更新到页面，避免因缓存失败而继续显示 Halo 的统计值。
- **侧栏路由**：主题脚本初始化后，桌面与移动侧栏的文章、分类和标签入口会读取 Halo 2.22+ 公开站点模型中的路由数据。旧版模型没有路由数据时，保留 `/archives`、`/categories` 和 `/tags` 默认入口。
- **文档整理**：重写 README，将详细配置与开发流程分别移入[配置文档](https://github.com/biliblihuorong/halo-theme-butterfly/blob/v2.3.1/docs/configuration.md)和[开发文档](https://github.com/biliblihuorong/halo-theme-butterfly/blob/v2.3.1/docs/development.md)，纠正随机文案 JSON 取值、图标子集和 CDN 资源等说明，并加入四张来自[博客](https://blog.ning.moe/)的真实截图。

本次没有新增配置字段，现有配置无需迁移。普通独立页面继续使用通用侧栏，不提供文章目录；瞬间与图库的业务代码未作调整。

## 升级

1. 从发行版下载 `theme-butterfly-dist.zip`，在 Halo 后台上传覆盖安装。
2. 建议清理浏览器或 CDN 缓存，确认主题 CSS/JS 请求中的版本参数为 `v=2.3.1`。
3. 静态资源来源建议保持“本站”；使用自定义 CDN 时，同步上传本版本的完整 `templates/assets/`，避免混用旧资源。

发行包附带 `.sha256` 与 `.manifest.json` 校验文件。配置项缺失时可在主题详情页执行“重载主题配置”。

## 验证

- 64 项回归测试通过，覆盖 Umami 缓存失败时的显示更新，以及桌面与移动侧栏的路由更新和默认入口回退。
- 对源码与压缩后的配置模板执行 JavaScript 内联验证，覆盖包含路由数据和不包含路由数据的新旧 `site` 模型。
- 完整构建、发行包检查、ZIP 完整性检查与 SHA-256 校验通过。
