# Butterfly v2.3.4

本版为本分支启用独立的 Halo 主题标识 `theme-butterfly-shell`，解决原 `theme-butterfly` 标识已由上游应用占用、无法作为独立应用提交市场的问题。

## 安装与迁移必读

**v2.3.3 及以前需要通过“安装主题”安装本版，迁移配置后再启用，不能在旧 `theme-butterfly` 上直接点“升级”。** Halo 根据 `metadata.name` 识别主题，新标识会作为独立主题安装。

1. 保留旧主题并备份配置，从发行版下载新的 `theme-butterfly-dist.zip`，通过主题管理的“安装主题”上传。
2. 按[标识迁移说明](https://github.com/biliblihuorong/halo-theme-butterfly/blob/v2.3.4/docs/configuration.md#从旧主题标识迁移到-v234)导出旧设置，用 `scripts/migrate-theme-identity.cjs` 离线转换，再写入新主题配置。
3. 预览、启用新主题，确认资源、菜单、封面与评论正常后，再决定是否卸载旧主题。已有文章、页面、菜单与元数据无需重建。
4. 之后的版本将保持 `theme-butterfly-shell` 标识稳定，可在这个新主题下正常升级。

## 变更

- **独立资源**：Theme 标识改为 `theme-butterfly-shell`，Setting 为 `theme-butterfly-shell-setting`，ConfigMap 为 `theme-butterfly-shell-configmap`。菜单与文章扩展表单也使用稳定的新主题专属名称，保留原来的 `icon` 与 `enable_code_copy` 字段。
- **市场元信息**：补齐 `homepage`、`issues` 与 GPL-3.0 许可声明。尚未取得本应用的市场 ID，本版不填写 `store.halo.run/app-id`；后续获得真实 ID 后再绑定。
- **资源路径**：本站资源地址根据当前主题标识生成，Prism 回退与内置默认背景跟随新目录；cursor 改用相对资源地址。旧默认本站地址可以映射到新目录，自定义 CDN、npm 和非默认资源地址保留。
- **配置迁移**：新增离线工具，支持纯 JSON 设置与完整 ConfigMap JSON/YAML，转换内部资源路径并保留其他配置。输出文件使用私密权限，不修改输入、不覆盖已有输出，也不连接站点。
- **发布校验**：打包时核对 Theme、Setting、ConfigMap 与扩展表单的命名一致性，防止再次发布沿用上游标识的制品。

仓库名、页脚项目链接和安装包文件名仍保持原有名称。ImgNest 多尺寸接口继续留待后续接入。
