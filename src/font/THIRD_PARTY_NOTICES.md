# Third-party fonts

The font files in this directory are optional theme assets. Each font keeps its
license alongside the WOFF2 files.

## Noto Sans SC

- Version: Fontsource package `@fontsource/noto-sans-sc@5.3.0`, weight 400,
  Simplified Chinese web subset
- Upstream: https://github.com/notofonts/noto-cjk
- Package source: https://fontsource.org/fonts/noto-sans-sc
- License: SIL Open Font License 1.1 (`NotoSansSC/OFL.txt`)

## Manrope

- Version: Fontsource package `@fontsource/manrope@5.3.0`, weight 400, Latin and
  Latin Extended web subsets
- Upstream: https://github.com/sharanda/manrope
- Package source: https://fontsource.org/fonts/manrope
- License: SIL Open Font License 1.1 (`Manrope/OFL.txt`)

## Resource Han Rounded CN

- Version: 0.990, CN Regular
- Upstream and release: https://github.com/CyanoHao/Resource-Han-Rounded/releases/tag/v0.990
- License: SIL Open Font License 1.1 (`ResourceHanRoundedCN/OFL.txt`); additional
  project clarification in `ResourceHanRoundedCN/LICENSE.md`
- Local processing: the official TTF was converted to WOFF2 with `wawoff2@2.0.1`;
  the font outlines and internal names were not changed
